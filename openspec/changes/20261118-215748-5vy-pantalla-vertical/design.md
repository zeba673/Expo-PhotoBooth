# Diseño

Electron abre la cabina en pantalla completa en el monitor configurado como vertical en Windows. Si no hay uno, abre una ventana vertical para preparar la cabina. La interfaz usa una columna en todas las etapas, con progreso horizontal, zonas de lectura amplias y acciones grandes. La cámara muestra el encuadre completo y el JPG mantiene el contenido de la captura.
